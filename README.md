# MushRoom-Acoustically-Transparent-Headphones
Acoustically Transparent Headphones. The design of the earcups is done by Alex Muelleder, and the original design, intructions, and specifications for drivers is available here: https://github.com/adude995/DIY-Open-Headphone. 

The Files are either in .stl format or .3mf. The Earcup model needs to be mirrored for printing the right earcup. For the pin part, 4x is required, and the headband part, 2x.
